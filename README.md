# Портфолио — как пользоваться

```
video-site/
  index.html     сайт
  admin.html     админка (работы, цены, тексты, публикация)
  data.json      весь контент — его меняет админка
  loops/         короткие лупы для спирали (необязательно)
  make-loop.bat  делает лупы из ваших роликов
```

## 1. Ролики на Vimeo

- Полный ролик живёт на Vimeo. В админке вставляете **ссылку или код встраивания целиком** — название, превью и формат (16:9 или 9:16) подставятся сами.
- В настройках ролика на Vimeo встраивание должно быть разрешено (Privacy → Embed: «Anywhere» или ваш домен). Иначе админка покажет ошибку при проверке.
- Ролик «по ссылке» (unlisted) тоже работает — копируйте ссылку целиком, вместе с кодом после номера.

## 2. Обложки карточек

Каждая карточка в спирали — обложка 4:3. В админке у работы два режима:

- **Дизайн** — собирается сама: кадр с Vimeo + название бренда крупно + ваш логотип (png с прозрачным фоном) + цвет акцента. Рилс 9:16 стоит справа «телефоном», горизонтальный ролик — сверху. Слева в админке сразу видно, как будет выглядеть.
- **Своё фото** — загружаете любую картинку (например, сделанную в Figma/Photoshop 1200×900), админка сама обрежет до 4:3 и сожмёт.

Файлы попадают в папки `covers/` и `logos/` при публикации.

## 2.1. Лупы для спирали (по желанию)

Все карточки в спирали одного формата — **4:3**, как у оригинала. Без лупа в карточке стоит превью с Vimeo, обрезанное по центру. С лупом карточка **оживает при наведении**. В плеере ролик всегда показывается в своём настоящем формате (16:9 или 9:16).

Лучший луп: **960×720 (4:3), 3–6 секунд, mp4, без звука**. Можно смонтировать отдельно в этом формате, или:

1. Один раз установите ffmpeg: `winget install Gyan.FFmpeg`
2. Перетащите исходники на `make-loop.bat` → в папке `loops/` появятся файлы 960×720 по 1–3 МБ (обрезка по центру, первые 5 секунд).
   Начать не с нуля: `make-loop.bat ролик.mp4 12` — с 12-й секунды.
3. В админке у работы: «Луп для спирали» → «Выбрать файл».

## 3. Хостинг бесплатно (один раз)

1. Зарегистрируйтесь на github.com, создайте репозиторий (например `portfolio`) и загрузите в него **содержимое** папки `video-site` (Add file → Upload files).
2. Зайдите на dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git → выберите репозиторий. Build command — пусто, output directory — `/`. Deploy.
3. Сайт будет на `https://<имя>.pages.dev`. Свой домен подключается там же (Custom domains).

## 3.1. Аналитика: кто заходил и из каких стран (бесплатно)

Используется **Cloudflare Web Analytics**: страны, количество визитов за день / неделю / месяц, устройства, откуда пришли. Без cookies, баннер про cookies не нужен.

Самый простой путь, если сайт на Cloudflare Pages:
1. dash.cloudflare.com → Workers & Pages → ваш проект → **Metrics** → **Web Analytics → Enable**. Всё, код вставлять не нужно.

Если сайт на другом хостинге (Netlify и т.п.):
1. dash.cloudflare.com → **Web Analytics** → **Add a site** → впишите адрес сайта.
2. Cloudflare покажет кусок кода — скопируйте из него значение `token` (длинная строка из букв и цифр).
3. Админка → **Сайт** → «Аналитика» → вставьте токен → **Опубликовать**.

Смотреть статистику: Cloudflare → Web Analytics → ваш сайт. Сверху выбирается период: последние 24 часа, 7 дней, 30 дней. Страны — блок «Countries». Ваши просмотры в «Предпросмотре» админки не считаются. Данные появляются с задержкой в несколько минут.

## 3.2. Логин и пароль на админку

Сайт работает как Cloudflare Worker: файл `worker.js` спрашивает логин и пароль у каждого, кто открывает `/admin`. Проверка идёт на сервере Cloudflare, без пароля страница не отдаётся. Сам пароль хранится в Cloudflare, а не в файлах сайта.

Задать или сменить пароль:
1. dash.cloudflare.com → Workers & Pages → `portfolio` → **Settings → Variables and Secrets → Add**.
2. Type: **Secret**, Variable name: `ADMIN_USER`, Value: ваш логин → Save.
3. Ещё раз **Add**: Type **Secret**, name `ADMIN_PASS`, Value: пароль → Save. Лучше латиницей и цифрами, от 12 символов.
4. Пока они не заданы, админка закрыта для всех (это специально — чтобы не оказалась открытой по ошибке).

Файлы `worker.js`, `wrangler.jsonc`, `.assetsignore` обязательно должны лежать в репозитории рядом с `index.html`. `.assetsignore` прячет служебные файлы (worker.js, README и т.д.) с сайта.

## 3.3. Статистика в админке (вкладка «Статистика»)

Показывает за сегодня / 7 / 30 дней: визиты, страны с флажками, какие ролики открывали, что нажимали (цены, пакеты, «заказать», фильтры, логотипы брендов). Хранится в бесплатной базе Cloudflare D1, IP-адреса не сохраняются, боты отсеиваются.

Подключить базу (один раз):
1. dash.cloudflare.com → **Storage & databases → D1 → Create** → имя `portfolio-stats` → Create.
2. Скопируйте **Database ID** (длинный номер на странице базы).
3. Откройте `wrangler.jsonc` в репозитории на GitHub (карандаш «Edit»), внизу есть заготовка: вставьте номер вместо `PASTE-ID-HERE` и уберите `//` перед тремя строками `,"d1_databases"…`. Commit.
4. Через минуту Cloudflare пересоберёт сайт — статистика начнёт копиться. Таблица в базе создаётся сама.

## 4. Админка

Открывайте `https://<имя>.pages.dev/admin.html`.

- **Работы** — добавить по ссылке Vimeo, порядок перетаскиванием, категория, описание, формат, луп. Внизу у каждой работы — **ссылка для клиента**, она открывает сразу этот ролик.
- **Цены** — пакеты для кнопки price.
- **Сайт** — имя, подпись, about, почта, ссылка для связи (Telegram/WhatsApp), соцсети.
- **Предпросмотр** — показывает сайт с вашими изменениями до публикации.
- Всё сохраняется в черновик автоматически, ничего не потеряется при закрытии вкладки (кроме ещё не опубликованных файлов лупов — админка предупредит).

### Публикация одной кнопкой (настроить один раз)

1. github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate.
   - Repository access: только ваш репозиторий портфолио.
   - Permissions → Repository → **Contents: Read and write**.
2. В админке → «Публикация»: репозиторий `username/portfolio`, ветка `main`, вставьте токен, поставьте «запомнить».
3. Дальше просто жмёте **«Опубликовать»** — через минуту сайт обновлён.

Токен храните только у себя: он даёт право менять этот репозиторий. Если засветился — удалите его на GitHub и создайте новый.

## 5. Ссылки для клиентов

- `https://<имя>/qfitness` (или `/#qfitness`) — сразу открыть конкретную работу.
- `https://<имя>/#rilsy` — показать в спирали только категорию (русское название пишется латиницей: «рилсы» → `rilsy`).
- `https://<имя>/qfitness/3` (или `/#qfitness/3`) — открыть проект сразу на 3-м ролике.

## 6. Проект с несколькими роликами

В админке, во вкладке «Работы», у проекта есть блок «Ещё ролики»: вставьте одну или несколько ссылок Vimeo, название и кадр подтянутся сами; порядок меняется стрелками (лучший ролик — первым). На сайте это одна карточка с плашкой «▶ N роликов». В плеере справа появляется кнопка «следующий ролик», работают стрелки на клавиатуре и свайп; после ролика 3 секунды идёт отсчёт и включается следующий, после последнего — экран «это всё по бренду» с другими проектами и кнопкой «заказать». Просмотренные проекты слегка затемняются (только у самого посетителя).

## 7. Цены и техника

Пакет: старая цена и плашка выгоды дают зачёркнутую цену и «−20%»; бейдж «новинка» красится в фиолетовый, «скидка»/«выгодно» — в оранжевый, остальные — в зелёный. У каждой позиции техники можно написать «подробно» — это текст на её отдельной странице.

## Проверить у себя на компьютере

```
py -m http.server 5179 -d video-site
```
и откройте http://localhost:5179 (двойной клик по index.html не сработает — браузер не даст прочитать data.json).

## 8. Как залить обновление на GitHub (сайт обновится сам)

1. Откройте репозиторий на github.com → **Add file → Upload files**.
2. Перетащите файлы: `index.html`, `admin.html`, `worker.js`, `cover.js`, `wrangler.jsonc`, `.assetsignore`, `favicon.svg`, `README.md`. Совпадающие файлы заменятся.
3. Внизу выберите **Commit directly to the main branch** → **Commit changes** (не «create a new branch» — иначе получится pull request).
4. Cloudflare сам пересоберёт сайт за 1–2 минуты (Workers → portfolio → Deployments: последняя строка зелёная).
5. Откройте сайт и нажмите **Ctrl+F5**.

`data.json` вручную не заливайте — контент (ролики, цены, бренды, фото «обо мне») меняется в админке и публикуется кнопкой «Опубликовать».
